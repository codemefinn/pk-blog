When adding custom code to Carrd using Embed elements, choose the appropriate **Style** option for each type of code.

- **CSS (`<style> ... </style>`)** — Set the Embed Position to **Head**.
- **JavaScript (`<script> ... </script>`)** — Set the Embed Position to **Body End**.
- **HTML contents** — Set the Embed Position to **Inline**.
