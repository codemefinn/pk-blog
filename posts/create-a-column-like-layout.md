excerpt: "~Create a more flexible column-like layout in Carrd using a two-column gallery and a transparent image.~"
---

Set the Gallery Style to Fixed and choose 2 columns. 
Add a transparent image as one of the gallery items, then enable Show Captions. 
This simple trick lets you work around Carrd’s column limit and create more flexible layouts.
