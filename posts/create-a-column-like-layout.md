Carrd’s container element has a column limit, but there's a simple trick you can use to create more flexible layouts.

Set the Gallery **Style** to **Fixed** and choose **2 columns**. Add a transparent image as one of the gallery items, then enable **Show Captions**.

That's it. You can now use this workaround to create column-like layouts that go beyond Carrd’s usual limits.
