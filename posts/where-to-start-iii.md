Carrd elements come with plenty of settings to customize their appearance, especially when it comes to alignment and spacing. But with so many options available, it can be difficult to know where to start.

A useful rule is to work from **top to bottom**, moving from the overall layout to the smaller details:

**Page → Container → Element**

Here's how it works:

Start with the **Page-level settings**. These establish the default rules for the content inside the page.

When an element's **Contents** or **Alignment** setting is set to **Auto**, it inherits the corresponding setting from its parent — either the Page or its Container.

You only need to change an element's settings manually when you want it to behave differently from its parent.

The same principle applies to **Animation settings**: start at the Page level, then adjust individual elements only when needed.

Following this approach keeps your settings consistent and makes complex layouts much easier to manage.
